# Hérika

Assistente pessoal para Windows: conversa por texto e voz usando a **sua** assinatura do Claude, conversa por voz em tempo real com o **seu** ChatGPT, agenda e e-mail (Google e Microsoft), tarefas e lembretes, Telegram, resumo da manhã e integração com o Revit (Revitiliano Brabo).

## Instalar

Baixe o `HerikaSetup-*.exe` da [versão mais recente](https://github.com/alanaraujoeu/herika/releases/latest) e execute. Não precisa de administrador nem de instalar .NET.

Na primeira abertura, a Hérika mostra as **Configurações** para você conectar as suas próprias contas. Os dados de cada pessoa ficam só na conta dela do Windows.

## Atualizações

Automáticas: pelo Revitiliano Brabo (membros VIP) ou, sem ele, pela própria Hérika.

Este repositório publica apenas os instaladores.
